# Intentional differences from the Python app

Every place where the Rust build deliberately behaves differently from the Python app (tag `python-final`,
commit 67609f6), and every Python bug found while porting (copied or fixed). Add an entry in the PR that
introduces a new difference. The WP column and the work-package references are from the rewrite
(`rewrite/PLAN.md`); paths like `805f5c0:rust/...` name files at commit 805f5c0, the last commit with the
Python app and the Rust port side by side (its Python tree is identical to `python-final`).

Kinds:

- **dropped**: legacy behaviour the plan removes (SQLite-dialect translation, CookieCloud cleanup,
  old-field startup migrations, tqdm bars).
- **mechanism**: same observable behaviour, different machinery (for example grammers instead of Telethon).
- **observable**: a user, the front end, an API client or stored data can tell the difference.
- **python-bug**: a bug found in Python; say whether Rust copies it or fixes it, and why.
